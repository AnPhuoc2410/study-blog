## Overview

**Firefly** is a clean, modern blog theme built on Astro and Svelte 5.

### Core Features

- [x] **Astro + Tailwind CSS** &mdash; Fast static site generation with flexible styling.
- [x] **Smooth Transitions** &mdash; Page navigation with Swup.
- [x] **Responsive Layout** &mdash; Optimized for mobile, tablet, and desktop screens.
- [x] **Internationalization (i18n)** &mdash; Full multi-language support.
- [x] **Full-Text Search** &mdash; Client-side search indexing with Pagefind.
