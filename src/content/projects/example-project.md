## About Study Blog

**Study Blog** is a personal learning portal and technical blog.

### Key Features

- ⚡ **Ultra Fast Static Generation:** Built on Astro 7 with zero-JS by default for static content.
- 🎨 **Modern Design:** Responsive layout, sleek dark/light modes, and custom color accents.
- 🔍 **Instant Search:** Full-text offline client search with Pagefind.
- 📐 **Math & Diagrams:** First-class KaTeX formula support and Mermaid diagram rendering.
- 🌐 **Clean Architecture:** Standardized TypeScript configurations and modular UI components.
